### #81 本地生成 PDF

先同步作者源码：

```bash
python3 scripts/sync_books.py --scope local-only
```

安装了较完整的 TeX Live、`latexmk` 和 `unzip` 后：

```bash
bash scripts/build_how_logic_works.sh
```

成功后会得到：

```text
books/local-only/81-How-Logic-Works-Hans-Halvorson/81-How-Logic-Works-Hans-Halvorson.pdf
```

因为作者源码仓库当前没有明确 LICENSE，本地构建产物也不提交到公开仓库。

## 后续扫描规则

1. 先找作者、出版社、政府/高校机构、Project Gutenberg、Internet Archive/Open Library 等可信来源。
2. 能合法公开再分发的完整文件，加入 `public-domain`。
3. 能由官方合法下载但不确认允许重新发布的完整文件，加入 `local-only`。
4. Borrow/Preview/付费电子书只记录来源，不绕过访问控制，不从非授权下载站获取。
5. 对“论文/演讲/报告”和“正式图书”严格区分，避免把配套材料标成整本书。
